# Neha Amin Portfolio

[![Built with Astro](https://astro.badg.es/v2/built-with-astro/small.svg)](https://astro.build)

A modern, accessible personal portfolio website showcasing my achievements, projects, and professional journey. Built with cutting-edge web technologies and accessibility best practices.

## Getting Started

Clone this portfolio locally and run any of the following commands in your terminal:

| Command           | Action                                       |
| :---------------- | :------------------------------------------- |
| `npm install`     | Installs dependencies                        |
| `npm run dev`     | Starts local dev server at `localhost:4321`  |
| `npm run build`   | Build your production site to `./dist/`      |
| `npm run preview` | Preview your build locally, before deploying |
